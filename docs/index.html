Workspace shape

One repository, multiple layers

Core path

vb6parse is the foundation: tokenizer, parser, CST, library documentation, wasm playground, coverage, and benchmarks.

Analysis path

vb6semantic, vb6runtime, and vb6core build the semantic and execution layers that sit above parsing.

Migration path

vb6convert, vb6codegen, vb6compile, and vb6libraries define the conversion and code-generation toolchain.

Immediate work

What still needs to be built

vb6harness

vb6harness is needed to confirm the exactness of vb6runtime/vb6interpret vs the VB6 IDE.

vb6convert

vb6compile requires vb6convert in order to produce rust code to compile so vb6convert is in the critical path.

vb6compile

One of the final goals of the vb6 umbrella project is to be able to completely replace vb6, and a compiler is important for that!
