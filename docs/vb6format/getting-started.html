Introduction

This guide will walk you through using VB6Format, from installation to advanced formatting scenarios. By the end, you'll understand how to format VB6 source files, customize formatting rules, and build tools that programmatically reformat Visual Basic 6 code.

Prerequisites

  • Rust: Version 1.70 or later (Install from rustup.rs)
  • Basic Rust knowledge: Understanding of Result types, ownership, and cargo
  • VB6 familiarity: Helpful but not required

Installation

1

Create a new Rust project

cargo new vb6format-demo
cd vb6format-demo
2

Add VB6Format to Cargo.toml

[dependencies]
vb6format = "0.1.1"
3

Verify installation

cargo build

Your First Format: Hello World

Let's start with the simplest possible example - formatting a VB6 module with a single subroutine.

1

Create a simple formatter

Replace the contents of src/main.rs:

use vb6format::{fmt_source, FmtSettings};

fn main() -> anyhow::Result<()> {
    let source = r#"Sub Foo()
If True Then
x=1
End If
End Sub"#;

    let settings = FmtSettings::default();
    let formatted = fmt_source(source, &settings)?;

    println!("{}", formatted);
    // Output:
    // Sub Foo()
    //     If True Then
    //         x = 1
    //     End If
    // End Sub

    Ok(())
}
2

Run the example

cargo run
💡 Key Concept: fmt_source
fmt_source takes the raw source string and FmtSettings, then returns a formatted string wrapped in Result. The default settings provide sensible formatting rules for standard VB6 code.

Customizing Formatting Rules

VB6Format provides FmtSettings for fine-grained control over formatting behavior:

use vb6format::{fmt_source, FmtSettings};

fn main() -> anyhow::Result<()> {
    // Create custom settings
    let settings = FmtSettings {
        indent_size: 4,
        blank_lines_around_directives: true,   // Add blank lines around #If/#End If
        blank_lines_inside_directives: true,   // Add blank lines between #ElseIf and its body
        blank_lines_around_top_level: true,    // Add blank lines between top-level constructs
    };

    let source = r#"#If True Then
Sub Foo()
x = 1
End Sub
#Else
Sub Bar()
y = 2
End Sub
#End If"#;

    let formatted = fmt_source(source, &settings)?;
    println!("{}", formatted);

    Ok(())
}
💡 Settings Reference:
indent_sizeSpaces per indent level (default: 4)
blank_lines_around_directivesBlank line before #If and after #End If (default: false)
blank_lines_inside_directivesBlank lines between directives and bodies (default: false)
blank_lines_around_top_levelBlank lines between procedures and top-level constructs (default: true)

Formatting VB6 Source Files

For real-world usage, you'll typically format entire files:

use vb6format::{fmt_source, FmtSettings};
use std::fs;

fn format_file(path: &str) -> anyhow::Result<()> {
    let source = fs::read_to_string(path)?;
    let settings = FmtSettings::default();
    let formatted = fmt_source(&source, &settings)?;
    fs::write(path, formatted.as_str())?;
    println!("Formatted: {}", path);
    Ok(())
}

fn main() -> anyhow::Result<()> {
    format_file("Module1.bas")?;
    format_file("Class1.cls")?;
    format_file("Form1.frm")?;
    Ok(())
}
⚠️ Important: The formatter works on individual source files (.bas, .cls, .frm). It does not process .vbp project files directly. Each module, class, and form file must be formatted individually.

Formatting Rules

VB6Format applies these rules automatically:

Block Indentation

Properly indents bodies of Sub/Function/Property, If/ElseIf/Else, For/Do/While/With/Select/Case, Type/Enum blocks

Closing Keywords

End If, End Sub, Loop, Next, etc. are un-indented to their parent level

Else/ElseIf Handling

Else, ElseIf, and Case act as both closers and openers - un-indented then followed by indented body

Compiler Directives

#If/#ElseIf/#Else/#End If blocks are indented correctly, with configurable blank line handling

Single-Line If

Single-line If Then statements are preserved on one line (e.g., If x = 1 Then y = 2)

Comments & Blank Lines

All comments and blank lines are preserved in their original positions

Common Use Cases

Here are some practical applications you can build with VB6Format:

CICD Formatting Checks

Integrate VB6Format into CI/CD pipelines to ensure consistent formatting across your VB6 codebase. Check formatted output against source to detect formatting drift.

Code Reformatters

Build batch formatting tools that reformat entire VB6 projects with a single command. Perfect for legacy codebases with inconsistent formatting.

IDE Integration

Integrate formatting into editor tools that format VB6 code on save or on demand. Use the library as a code quality tool in custom IDE plugins.

Migration Tools

Standardize formatting before running code migration or conversion tools. Consistent input formatting makes subsequent processing more reliable.

aspen fmt

VB6Format is the formatting engine behind aspen fmt, the command-line VB6 code formatter tool. Use aspen for interactive formatting from the terminal.

Code Reviews

Automatically flag formatting inconsistencies in pull requests. Require clean formatting as part of code review process for VB6 projects.
