Documentation Overview

VB6Format is designed as a high-performance formatter for Visual Basic 6 source code. It takes raw VB6 source files and produces consistently formatted output while preserving comments, blank lines, and the original code's structure. Built on top of vb6parse's Concrete Syntax Tree, it provides source-fidelity formatting that respects every detail of the original code.

Key Features

🚀 High Performance

Fast formatting powered by Rust, with minimal allocations and efficient CST traversal

📋 Full VB6 Support

Formats modules (.bas), classes (.cls), forms (.frm), and all VB6-specific constructs

Architecture

VB6Format uses a pipeline-based approach that transforms raw source code into consistently formatted output. The formatter leverages vb6parse's Concrete Syntax Tree to ensure no source information is lost, then applies a series of formatting passes to produce clean, consistent output.

Formatting Passes

Layout Pass

Input: CST from vb6parse

Output: Properly indented code

Purpose: Fixes indentation for block bodies, closing keywords, and nested constructs. Handles Sub/Function/Property, If/ElseIf/Else, For/Do/While/With/Select, and compiler directives.

Keyword Pass

Input: Layout-passed CST

Output: Correctly cased keywords

Purpose: Normalizes keyword casing (e.g., 'sub' → 'Sub', 'end if' → 'End If') to match VB6 conventions.

Spacing Pass

Input: Keyword-passed CST

Output: Consistent blank lines

Purpose: Manages blank lines between top-level constructs and around compiler directives, with configurable behavior.

Line Ending Pass

Input: Spacing-passed CST

Output: Consistent line endings

Purpose: Normalizes line endings to a consistent format (CRLF for VB6 convention).

💡 Chained Passes: Each formatting pass operates on the CST incrementally. The passes are designed to be independent and composable, allowing fine-grained control over which formatting rules are applied.
